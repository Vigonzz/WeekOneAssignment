The program WeekOneAssignment peruses through the book Pride and Prejudice
provided through GitHub specifically from Proffesor: Cristina Videira Lopes. From
scanning the book, this program provided the top 25 most used words while implementing
the term frequency program without following a direct style!

To Run the program:

 1. Ensure you have Java version 11 or later and
 correctly pathed in your computer's environment.

 2. Have the files stop_words.txt and pride-and-prejudice.txt specifically in the WeekOneAssignment folder. It
 should be one level above the source folder. Without these files in the correct location the program cannot
 run correctly.

 3. Open your terminal and change directories: cd path/to/WeekOneAssignment/src
 to enter the program's source folder. You should be able to now identify the file WeekOne.java here.
 Then enter the following:
 java WeekOne.java ../pride-and-prejudice.txt

 4. Look at the fun list of words and their count!
